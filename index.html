01 / ESTRUTURA

O que é a estrutura?

A tabela de hash (ou tabela de dispersão) é uma estrutura de dados que associa chaves a valores. Ela usa uma função matemática para converter cada chave em um índice do vetor, permitindo localizar o valor sem percorrer toda a lista.

Pense como um armário de chaves

Imagine um armário com várias gavetas numeradas. Em vez de procurar em todas, você usa a chave para descobrir exatamente qual gaveta abrir. Se duas chaves apontarem para a mesma gaveta, elas ficam enfileiradas dentro dela — é o que chamamos de colisão.

03 / FUNCIONAMENTO

Como funciona?

O fluxo é simples: converter a chave, encontrar a posição, tratar colisões e armazenar o par.

01

Receba a chave

Toda operação começa pela chave: "nome", 42, user_17...

02

Aplique a função hash

A função transforma a chave em um número, depois limita esse número ao tamanho do vetor.

03

Resolva colisões

Se a posição estiver ocupada por outra chave, encadeie ou sondagem até encontrar espaço.

04

Guarde ou recupere

Insira o par na posição calculada — ou leia o valor armazenado na busca.

a conta por trás da mágica
índice = hash(chave) MOD tamanho_do_vetor

Exemplo com 8 posições: se hash("curso") = 27356, então 27356 % 8 = 4 e o par vai para a posição 04.

Custo das operações

Com uma boa função hash e poucas colisões, o acesso é praticamente constante. No pior caso, todas as chaves caem na mesma posição e a busca vira linear.

hash-table.js
class TabelaHash {
  constructor(tamanho = 8) {
    this.buckets = Array.from({ length: tamanho }, () => []);
  }

  hash(chave) {
    let h = 0;
    for (const c of chave) {
      h = (h * 31 + c.charCodeAt(0)) % 100000;
    }
    return h % this.buckets.length;
  }

  inserir(chave, valor) {
    const i = this.hash(chave);
    const par = this.buckets[i].find(p => p[0] === chave);
    if (par) par[1] = valor;          // atualiza
    else this.buckets[i].push([chave, valor]); // colisão → encadeamento
  }

  buscar(chave) {
    const bucket = this.buckets[this.hash(chave)];
    return bucket.find(p => p[0] === chave)?.[1] ?? null;
  }
}
